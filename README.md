# DAW-ITIID-223 -- Davo Blas

Repositorio académico del curso de Desarrollo Web donde se almacenan prácticas, ejercicios y proyectos realizados como parte de la materia. El proyecto principal es un portafolio personal desarrollado con HTML, CSS, JavaScript y PHP, con una vista pública y una sección de administración para gestionar mensajes recibidos.

## Autor
- David Blas
- Universidad Politécnica / materia: Desarrollo Web

## Descripción general
Este repositorio reúne dos secciones principales:

- `hola-PHP/`: ejemplo básico de integración de PHP con HTML.
- `Mi-Portafolio/`: proyecto del portafolio personal, con estructura modular y diseño responsivo.

## Proyecto principal: Mi Portafolio
La carpeta `Mi-Portafolio` contiene una página personal con:

- Inicio y presentación personal
- Sección "Sobre mí"
- Habilidades técnicas
- Proyectos destacados
- Formulario de contacto
- Panel de administración (`PHP/admin.php`)

### Tecnologías utilizadas
- HTML5

- JavaScript
- PHP
- MySQL (aplicado en la lógica del proyecto escolar)

## Requisitos
Para ejecutar el proyecto localmente se recomienda:

- XAMPP / WAMP / MAMP
- PHP
- MySQL
- Navegador web moderno

## Cómo ejecutar
1. Clona este repositorio.
2. Colócalo dentro de la carpeta de tu servidor local (`htdocs` si usas XAMPP).
3. Inicia Apache y MySQL.
4. Abre en el navegador:

```bash
http://localhost/DAW-ITIID-223--DavoBlas/Mi-Portafolio/index.html
```

5. Para acceder al panel administrativo:

```bash
http://localhost/DAW-ITIID-223--DavoBlas/Mi-Portafolio/PHP/admin.php
```
